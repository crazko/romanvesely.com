To keep git commit history clean one oftentimes need to use [`git rebase --interactive`](https://git-scm.com/docs/git-rebase#_interactive_mode) to fix or rename older additions.
There are several [newer git commands](https://lalitm.com/post/git-history/) that make those operations easier:

[`git history reword <commit>`](https://git-scm.com/docs/git-history#Documentation/git-history.txt-rewordcommit) to easily change the commit message

[`git history fixup <commit>`](https://git-scm.com/docs/git-history#Documentation/git-history.txt-fixupcommit) to easily amend older commit with currently staged changes
